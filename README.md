# 末日突围 —— Godot 4.7 横版射击 Demo

一款类《CF暴击僵尸2015》的末日横版射击游戏（原创，规避版权：自研像素美术、新名字）。

## 怎么运行
1. 用 **Godot 4.7.1** 打开本文件夹（`D:\末日突围（游戏开发中）\末日突围`）
2. 按 **F5** 运行，会先进入**选人界面**
3. 点任意一个角色（司机 / 医生 / 警察 / 军人 / 维修工 / 程序员）进入游戏

> 首次运行若弹窗让你选主场景，确认 `Menu` 即可（主场景已设为 `Menu.tscn`）。

## 操作
- **W**：前进（向右）  /  **S**：后退（向左）
- **空格**：跳跃
- **J 键 / 鼠标左键**：射击（**自动瞄准**离你最近的丧尸，无需手动转向）

## 角色（开局赠送「司机」，其余可在选人界面解锁挑选）
| 职业 | 性别 | 说明 |
|------|------|------|
| 司机 | 男 | 开局即送，默认角色 |
| 医生 | 女 | — |
| 警察 | 男 | — |
| 军人 | 男 | — |
| 维修工 | 男 | — |
| 程序员 | 男 | — |

每个角色都是 AI 生成的末日像素图，带污渍/血迹，符合废土形象。

## 丧尸（3 种，从地面爬出来）
- **普通男丧尸**：爪子近战攻击，血量 3
- **女丧尸**：像原版一样**伸长舌头远程攻击**，血量 3
- **胖子丧尸**：血厚（血量 10），移动慢，近战

被打中会有受伤闪红 + 1 秒无敌帧；生命归零自动重开本关。

## 画面里现在有什么
- 主角：6 选 1 的职业像素小人（左上角 HUD 显示生命 ♥）
- 丧尸：3 种像素丧尸，从地面右侧爬出向你逼近
- 子弹：黄色小长条（自动朝最近丧尸飞）
- 背景：末日城市（房屋暗淡、部分倒塌），全屏铺底
- 地面：灰色长条

## 司机 + MP5 动态背景
新增 `art/background_driver_mp5_lamp.png`（1536x864）：司机手持第一把机枪 MP5，靠在废弃汽车旁，远处是丧尸和围城废墟，路灯为暖色视觉焦点。

新增 `CinematicBackground.tscn` 与 `background_lamp.gd`：实例化这个场景即可播放动态背景。背景大图保持单张纹理，只有路灯光晕在 Godot 中以低成本 Sprite2D 层动画，每 6 秒闪烁一次。

`art/background_driver_mp5_lamp.gif` 是 768x432、6 秒循环的动图预览；游戏内建议使用 `CinematicBackground.tscn`，可避免 GIF 解码和重复纹理占用。

## 怎么加音乐 / 音效
1. 在项目里新建 `audio` 文件夹
2. 放 `bgm.ogg`（背景音乐，自动循环）和 `shoot.ogg`（开枪音效）
3. `AudioManager.gd` 会自动加载播放，无需改代码
